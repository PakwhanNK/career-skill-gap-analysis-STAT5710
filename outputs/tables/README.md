# Tables Directory

This folder is organized to keep final report outputs separate from intermediate or legacy tables.

## `final/`

Report-ready aggregate tables, model summaries, EDA summaries, hypothesis tests, PCA/k-means summaries, and year-over-year skill-shift tables generated by:

```powershell
python scripts/run_ready_analysis_classification.py
```

## `employer_review/`

Canonical employer label table:

```text
reviewed_companies.csv
```

This is the single source of truth for reviewed target/non-target employer labels. Older manual-review batch files are kept under `employer_review/archive_batches/`.

## `modeling_data/`

Row-level modeling datasets generated locally. These files are intentionally ignored by Git because they contain user-level rows.

## `archive/`

Older outputs from previous analysis versions and pre-cleanup root-level tables.

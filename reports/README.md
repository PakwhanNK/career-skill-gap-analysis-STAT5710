# Reports

This folder contains the final report source and report-ready figures.

## Main Files

- `final_report.tex`: main LaTeX report source.
- `final_project_report_updated.md`: Markdown copy of the report narrative.
- `figures/`: figures referenced by the report.

## Figure Notes

The report uses `\graphicspath{{figures/}}`, so the files in `reports/figures/` are the easiest set to upload to Overleaf with `final_report.tex`.

Most figures are generated by `scripts/create_latex_report_assets.py` from aggregate outputs in `outputs/tables/final/`. The word-cloud PNGs come from the uploaded word-cloud script and are kept here as report assets.
